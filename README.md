# Eclipse V.2

Welcome to the Eclipse V.2 project!

## Overview
Eclipse V.2 is a web-based platform inspired by Chrome OS aesthetics, featuring a modern interface and multiple utilities. The project includes themed pages, interactive UI elements, custom navigation, and web-based applications.

## Features
- Chrome OS themed homepage and UI
- Custom search form and navigation
- Web-based "player" and utility pages
- Stylish, responsive design with custom CSS
- Modular JavaScript for UI interaction and service workers

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/7-7-7-15/7-7-7-15.github.io.git
   ```
2. **Open `index.html` in a web browser**

The site is designed to be hosted using GitHub Pages or any static site host.

## File Structure

- `index.html` - Main homepage
- `EclipseOS.html` - Chrome OS themed page
- `myplayer.html` - Web player page
- `explore/` - Additional scripts and service worker files
- `storage/` - Stylesheets and supporting JS
- `assets/` - Images, logos, backgrounds (add as needed)
